# 后端技术文档

# 技术栈

前端技术栈没有特别要求

数据库使用 mysql8.0以上版本

后段技术栈主要使用springboot2

# 数据表设计

每一张数据库中都应有这四个字段:

*   modified\_user: String.  对记录进行更新的用户id. 除特殊说明, 这一个字段都应填做修改的用户id.
    
*   created\_time: Date.  记录创建的时间
    
*   modified\_time: Date.  记录更新的时间
    
*   deleted: Integer. 逻辑删除, 0表示未删除, 1表示被删除
    

出库发票表

sale\_invoice

```plaintext
invoice_id:String  主键
customer_id:Long  customer_info的主键
shipping_fee: Integer  运费
is_free_shipping: Boolean 是否付运费, true:生产商付; false:客户付
total_money: Double  本次出库的总金额
invoice_time: Date  开票日期
comment: String  发票备注
operater: String  开票人
```
